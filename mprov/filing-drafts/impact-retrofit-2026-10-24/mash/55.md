## Symptom

`bmc power cycle compute001` prints nothing regardless of what the mPCC power API returns, so operators and scripts cannot tell whether the command worked.

## Root cause

`do_power()` in `src/mash/plugins/bmc.py` assigned `session.get(...)` to a local and discarded it: no status check, no per-node output.

## Fix

For each node, check the response status and print one line to stdout — `<host>: <server result>` on 2xx, `<host>: ERROR code <n>: <body>` on HTTP errors, `<host>: ERROR <exception>` on transport errors (a dead node no longer aborts the rest of the range). When any node fails, also write a command-level `Error:` line to stderr so scripts can detect failure.

## Impact

Touches the bmc power command's feedback path. Before: nothing printed whatever the API returned; after: one per-node result line on stdout plus a command-level `Error:` on stderr. Files: `src/mash/plugins/bmc.py`, `tests/test_bmc_power.py`.
