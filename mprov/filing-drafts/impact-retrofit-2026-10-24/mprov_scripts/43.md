buildDisks takes each disk name from the layout the mPCC returns for this system and immediately calls freshDisk on it, which writes a new empty partition table and destroys whatever partitions the device had (`post-boot/localTempDisk.py:127-128`, at `eb80617`). There is no validation between fetching the layout (line 209) and wiping (line 128): nothing checks that the target device is not the one the running system booted from.

**Fix:** before repartitioning, validate each target device — refuse to wipe the device backing the mounted root filesystem or any mounted partition, and optionally sanity-check device size or model against the layout.
