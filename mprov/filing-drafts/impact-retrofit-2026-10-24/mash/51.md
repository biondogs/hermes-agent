Fixes #27

`pvar foo,bar` — the comma-separated form advertised in the command's own help text — silently printed nothing when the variable names were longer than one character; single names printed fine. `do_pvar` fed the raw argument string to `csv.reader(arg)`: iterating a string yields single characters, so each parsed row held one character and multi-character names were never looked up.

## The fix
Split the argument on commas directly and strip whitespace from each name. Touches `do_pvar` in `src/mash/app.py` only; the `do_p` alias inherits the fix.

## Impact

Touches `pvar` argument parsing. Before: `pvar foo,bar` printed nothing for multi-character names; after: comma lists print the named variables. Files: `src/mash/app.py`, `tests/test_pvar.py`.
