  (self.config[field] += ...) which KeyErrors when the distro did not populate
  the key first; in practice CC-012's shared class dict masks this. Fixing
  CC-012 correctly will surface it — fixers should watch this interaction.
- JobServersAPIView serializes jobmodule ids twice (int pk and str) in its
  response; interop wart, not filed.
- OSDistro.create() compares float(version) >= 9 for rcd vs dnf logic; fragile
  parsing for a two-vendor branch, not filed.

  but is an unusual pattern.

  User.objects.get(pk=1) when no request user — same identity-forgery family
  as CC-038 but on audit defaults only.
- All app tests.py files are empty; there is no test suite in the repo at all
  (context for the R7 regression_test fields — none can run today).
- templates/docs.html contains an empty section list; stale doc page.
- README says "based off of Django 3.2" while unpinned requirements resolve
  4.x (covered by CC-028); deployment was reviewed against 4.2 semantics.
