Fixes #23

`bmc power on bmc001` reached the plugin as `power on 001`: every occurrence of the plugin name inside the arguments was stripped before the plugin saw them. `MprovShell.default()` already removes the plugin token via `args.split(" ", 1)`, then ran `args.replace(pluginName, "")` over the remainder, corrupting legitimate arguments that contain the plugin name (`bmc001` → `001`).

## The fix
Drop the substring replace. Set `args = ""` explicitly in the bare-invocation branch — the replace had been incidentally producing `""` for name-only commands — mirroring the existing pattern in `do_help`. Dispatch argument handling only; no other changes.

## Impact

Touches plugin command dispatch. Before: `bmc power on bmc001` reached the plugin as `power on 001`; after: arguments pass through untouched. Files: `src/mash/app.py`, `tests/test_plugin_dispatch.py`.
