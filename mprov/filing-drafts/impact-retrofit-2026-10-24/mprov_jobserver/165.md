`install_mprov_jobserver.sh` deploys a systemd unit fetched from raw.githubusercontent.com at install time, so the unit can drift from the released package it just installed — an install-time supply-chain and drift wart.

`install_mprov_jobserver.sh:71-72`: `wget -O /usr/lib/systemd/system/mprov_jobserver.service https://raw.githubusercontent.com/mprov-ng/mprov_jobserver/main/mprov_jobserver.service`. `mprov_jobserver.service` sits in the repo root and could ship with the package instead.

**Fix:** install the unit from the package payload (or a pinned tag), not the mutable main branch.

Impact: touches installer deployment of the systemd unit; prod today the unit is wget'd from the mutable main branch at install time, expected: the unit ships in the package payload or a pinned tag. Files: `install_mprov_jobserver.sh`, `mprov_jobserver.service`.
