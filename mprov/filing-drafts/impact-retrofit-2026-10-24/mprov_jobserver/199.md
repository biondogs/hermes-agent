**Symptom.** The script-runner writes the entity dict — including the fleet mPCC API key — to `/tmp/mprov-script-runner/entity.json` with default, world-readable permissions; a crashed run also left the file behind permanently. During post-boot runs this happens on every provisioned node.

**Root cause.** `script_runner.py` created the tmp workspace with `os.makedirs` default perms, wrote `entity.json` with the default file mode, and unlinked it only on the normal-completion path.

**Fix.** Create the tmp workspace `0700` (tightening one left behind by an older version), create `entity.json` via `os.open(..., 0o600)`, and unlink it in a `finally` block. `image_update.py` no longer writes key-bearing files on main, so it is untouched.

## Impact
Touches script-runner temp files. Before: the fleet API key sat world-readable in `entity.json` under the /tmp workspace, surviving crashed runs. After: 0700 workspace, 0600 `entity.json`, unlinked in a `finally`. Files: `src/mprov_jobserver/plugins/script_runner.py`, `tests/test_script_runner.py`.

**Test evidence.** 4 new regression tests: RED on base `df027c6` (4 failed), GREEN on head `8e663ab` (18 passed); full-suite failure set unchanged from base.
