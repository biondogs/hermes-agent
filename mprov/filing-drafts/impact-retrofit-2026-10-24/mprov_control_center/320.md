The authenticated system and kernel-commandline endpoints pick the client IP for the `?self` lookup header-first, so an authenticated caller — including any API-key holder — can select an arbitrary system's record by sending a forged X-Forwarded-For instead of only its own. **Fix:** restrict the `?self` lookup to the true socket address, honor forwarded headers only from configured trusted proxies, and make header-selected identity an explicit admin-scoped action.
