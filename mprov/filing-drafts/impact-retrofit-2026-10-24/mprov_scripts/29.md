The disk formatter writes the fstab entry for the partition mount point `part['mount']` (`post-boot/localTempDisk.py:147-149`, at `eb80617`) but then mounts `pdisk['mount']`, the field nested at the disk-layout level — and in the mPCC API `DiskLayoutAPISerializer.getMount` (mprov_control_center `disklayouts/serializers.py:38-43`) returns None for every disk whose dtype is not mdrd, so the mount call crashes on ordinary non-RAID disks.

**Fix:** mount the same mount point that was just written to fstab (the partition's mount field), or drop the explicit mount call entirely.

Impact: touches post-boot disk formatting; prod today fstab is written from the partition's mount
point but the mount call uses the disk-level field, which is None on non-RAID disks,
expected: mount the partition's own mount point. Files: `post-boot/localTempDisk.py`.

Severity: S2 — node provisioning crashes on every non-RAID disk layout.
