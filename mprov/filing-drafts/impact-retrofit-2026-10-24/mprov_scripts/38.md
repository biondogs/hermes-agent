backup-mprov.sh has no fail-fast error handling and no per-command status check (`tools/backup-mprov.sh:4-12`, `:30-34`, at `eb80617`): a failed cd at line 4, a failed venv activation at line 6, or any number of failed dumpdata invocations are all carried forward — the final statement is an echo, so the script exits 0 and prints "Backup saved to /tmp/mprov_backup.tar.gz" even when the tarball contains a partial or empty directory tree.
