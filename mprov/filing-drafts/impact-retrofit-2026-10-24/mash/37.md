Following mash's own backgrounding convention (`create ... &`), an operator writes `bmc power on node01 &` — and the command silently does nothing: plugins are invoked with `pluginInstance.onecmd` (`src/mash/app.py:105`), which never calls the plugin's `precmd`, so the ampersand-handling block is dead code and `self.background` is never consulted by `do_power` (`src/mash/plugins/bmc.py:52-56`, at `36b6a5e`).

**Fix:** Handle the trailing ampersand where the line actually enters the plugin (in the dispatch path or at the top of `do_power`), strip it before parsing the node spec, and honor it.

Impact: touches backgrounding of bmc commands; prod today a trailing `&` silently no-ops the command, expected: the marker is honored or rejected. Files: `src/mash/app.py`, `src/mash/plugins/bmc.py`.
